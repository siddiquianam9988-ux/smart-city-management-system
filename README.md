## ▶️ How to Run the Project

Follow these steps to run the Smart City Management System.

### Step 1: Download the Project

Download or clone this repository from GitHub.

### Step 2: Open the Project Folder

Open the downloaded project folder on your computer.

### Step 3: Open index.html

Find the `index.html` file and double-click it.

The website will open in your default web browser.

### Step 4: Navigate Through the Website

You can explore the following sections:

- Home
- Services
- Dashboard
- About
- Contact

### Step 5: Test the Features

You can test the following features:

- Dark Mode
- Mobile Navigation
- Service Buttons
- Contact Form
- Dashboard
- Navigation Links

## 🌐 GitHub Pages

This project can be hosted using GitHub Pages.

### Steps to Enable GitHub Pages

1. Open the GitHub repository.
2. Go to **Settings**.
3. Click on **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch.
6. Select `/ (root)`.
7. Click **Save**.
8. Wait for GitHub Pages to publish the website.
9. Open the generated website link.

⚠️ Project Limitations

This project is currently a frontend demonstration system.

The current version:

Does not have a real backend.
Does not use a real database.
Does not receive real-time IoT sensor data.
Uses demonstration data for the dashboard.
The contact form is for demonstration purposes.
Does not provide real-time city monitoring.
